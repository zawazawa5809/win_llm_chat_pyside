# Requirements Document

## Project Description (Input)

クリップボードから画像(スクリーンショット)の貼り付け機能(Ctrl+V)

## Requirements

### Scope

- インスコープ: Windows デスクトップ版 LLM チャットクライアントにおける、OS クリップボード上の画像データ（スクリーンショット等）をチャットメッセージに添付するための貼り付け操作（標準の貼り付けショートカット Ctrl+V）と、その表示・送信・保存までの一連の UX
- アウトオブスコープ: 画像編集機能（トリミング・モザイク等）、OCR や画像 → テキスト変換機能、画像の外部ストレージ連携、新しいファイル種別の永続化方式の抜本的変更

### Functional Requirements

- FR-1 クリップボード画像貼り付けトリガー

  - メッセージ入力欄（メッセージコンポーザ）がフォーカスされている状態で、OS クリップボードに画像データが存在する場合に Ctrl+V を押下すると、現在編集中のメッセージに画像が添付されなければならない
  - クリップボードに画像データが存在しない場合に Ctrl+V を押下しても、アプリはクラッシュしてはならず、テキスト入力内容を破壊してはならない

- FR-2 添付としての一貫した取り扱い

  - 貼り付けられた画像は、既存のファイル添付機能（v1.4）と同等の概念で「メッセージに紐づく添付オブジェクト」として扱われなければならない
  - 複数回 Ctrl+V を行った場合、複数枚の画像を 1 つのメッセージに添付でき、添付順序が送信時まで保持されなければならない
  - 画像を添付したメッセージを送信した後も、その画像はセッション履歴上で他の添付ファイルと同様に閲覧・再利用できなければならない

- FR-3 UI 表示と削除操作

  - 貼り付けた画像は、メッセージ入力欄付近の添付エリアにサムネイルまたは画像種別が分かるアイコンとして表示されなければならない
  - ユーザーは送信前に個々の画像添付を削除できる UI（例: 添付サムネイルの × ボタン）を持たなければならない
  - 画像添付を削除しても、メッセージ本文テキストや他の添付（ファイル・画像）は影響を受けてはならない

- FR-4 エラー処理とバリデーション

  - 画像サイズがアプリで定義された上限（設定または定数）を超える場合、アプリはユーザー向けのエラーメッセージを表示し、その画像を添付しない挙動を取らなければならない
  - サポート対象外の画像形式の場合も同様にエラーとして扱われ、クラッシュやハングを起こしてはならない
  - 画像貼り付け処理中に例外が発生した場合でも、アプリ全体は動作を継続し、少なくとも現在開いているセッションや入力中メッセージが失われないようにしなければならない

### Non-Functional Requirements

- NFR-1 パフォーマンスと応答性

  - 一般的なスクリーンショット（フル HD 程度）の貼り付け操作から、添付サムネイルが UI に表示されるまでの体感時間は、通常利用環境でストレスにならない範囲（目安として 500ms 前後以内）でなければならない
  - クリップボードに非常に大きな画像が含まれている場合でも、貼り付けの可否判定とエラー表示はタイムアウトやアプリフリーズを招かない方法で行われなければならない

- NFR-2 UX と誤操作防止

  - Ctrl+V による貼り付け操作は、既存の主要ショートカット（送信・検索・レイアウト切替など）と衝突しないように設計されていなければならない
  - クリップボードに画像がある場合とテキストのみの場合で Ctrl+V の挙動がどう切り替わるかについて、ユーザーにとって混乱にならないよう、ヘルプやショートカット一覧に明示されていなければならない

- NFR-3 セキュリティとプライバシー

  - クリップボードから取得した画像データは、当該メッセージおよびセッションに必要な範囲を超えて不要に保持・再利用されてはならない
  - ユーザーが明示的に送信していない画像がバックグラウンドで勝手にアップロードされるような挙動は発生してはならない

### Acceptance Criteria

- AC-1 クリップボードに PNG 形式のスクリーンショットが存在する状態でメッセージ入力欄をフォーカスし、Ctrl+V を押下すると、画像が添付サムネイルとして表示され、そのままメッセージ送信するとセッション履歴上に画像付きメッセージとして保存されること
- AC-2 クリップボードに画像が含まれていない状態で Ctrl+V を押下しても、アプリがクラッシュせず、メッセージ本文テキストや他の添付が変化しないこと
- AC-3 上限サイズを超える画像をクリップボードから貼り付けた場合、ユーザー向けのエラーメッセージが表示され、画像が添付されないことを確認できること
- AC-4 貼り付けた画像添付を送信前に削除でき、その操作が他の添付や本文テキストに影響しないことを確認できること
- AC-5 代表的な長時間利用セッションにおいて、複数枚の画像を貼り付け・送信しても、パフォーマンス劣化やメモリリークなどが顕在化しないことを簡易的な負荷試験または長時間動作確認で検証できること
