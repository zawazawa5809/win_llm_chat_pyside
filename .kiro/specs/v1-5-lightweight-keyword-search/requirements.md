# Requirements Document

## Project Description (Input)

@ROADMAP-v2.0.md の v1.5: 軽量キーワード検索（セッション／添付テキスト）

## Requirements

### Scope

- インスコープ: セッション内検索（Ctrl+F）、セッション一覧検索、添付テキスト検索（添付済みテキストに対するキーワード検索と LLM への補助プロンプト生成）、これらに付随する最小限の UI とキーボードショートカット
- アウトオブスコープ: ベクタ検索・全文検索エンジン・常駐インデックス構築、数千セッション／添付を前提としたスケーラビリティ最適化、サーバサイド検索機能や RAG 連携

### Functional Requirements

- FR-1 セッション内検索（Ctrl+F）

  - 現在アクティブなセッションのメッセージ本文（ユーザー／アシスタント／system を含むテキスト）を対象に、入力キーワードを大文字小文字無視で検索できること
  - 検索キーワードに一致した箇所をハイライト表示し、「次へ／前へ」操作で一致箇所間を順送り／逆送りで移動できること
  - 検索ダイアログ（または検索バー）はショートカット（デフォルト Ctrl+F）で開閉でき、閉じた時点でハイライト表示はクリアされること

- FR-2 セッション一覧検索

  - セッション一覧ペイン上で検索キーワードを入力すると、セッション名と冒頭数メッセージ分のプレーンテキストを対象にキーワード検索を行うこと
  - 検索結果は「マッチするセッションのみをリスト表示」または「各セッション行にヒットバッジを表示する」いずれかの UX とし、どのセッションがヒットしたか一目で判別できること
  - 検索実行時にのみローカルストレージ上のセッションデータ（JSON など）を走査し、バックグラウンドでの常駐インデックス更新や長時間ブロッキング処理を行わないこと

- FR-3 添付テキスト検索（オプション）
  - セッション内にテキスト抽出済みの添付ファイルが存在する場合、それらのテキストを対象にキーワード検索を行い、「どのファイルにヒットしたか」の簡易一覧を表示できること
  - 検索結果一覧から特定のファイル／ヒット箇所を選択すると、その周辺テキスト抜粋を含む補助プロンプトを組み立てて、現在のセッションに LLM リクエストを送れること
  - 添付機能が無効な場合や該当セッションに添付が存在しない場合、添付テキスト検索 UI は表示しないか、適切な無効状態表示とすること

### Non-Functional Requirements

- NFR-1 軽量性・非インデックス

  - いずれの検索機能も、その時点で存在するセッションデータ／添付テキストに対する「その場のフルスキャン」のみで完結し、永続的なインデックスやベクタストアを構築しないこと
  - セッション数・添付数が「人間が現実的に扱う範囲（数十〜数百程度）」であることを前提とし、それを超える規模での最適化はスコープ外であることを明示すること

- NFR-2 パフォーマンスと応答性

  - 想定規模（数十〜数百セッション、各セッションが通常のチャット長）において、検索実行から結果表示までが人間の業務利用でストレスを感じないレベル（目安として 1 秒前後以内）であること
  - 検索処理中も UI が完全にフリーズせず、必要に応じてシンプルなローディング表示やキャンセル手段を提供すること

- NFR-3 UX と一貫性
  - セッション内検索、セッション一覧検索、添付テキスト検索の入力 UI とショートカットは、できる限り一貫した位置・見た目・操作感で提供されること
  - ヒット件数が 0 件の場合は、その旨を明示的なメッセージで表示し、ユーザーが「反応がない」のか「単にヒットしていない」のかを判別できること

### Acceptance Criteria

- AC-1 通常規模のセッション履歴を持つ状態で Ctrl+F を押下し、任意のキーワードを入力すると、現在のセッション内の該当箇所が順送り／逆送りでハイライトされることを確認できること
- AC-2 セッション一覧ペインでキーワード検索を行った際、ヒットしたセッションのみが表示されるか、ヒットバッジが付与され、そこから対象セッションへ問題なく遷移できること
- AC-3 添付テキスト検索が有効なセッションでキーワード検索を行うと、ヒットした添付ファイル名が一覧表示され、クリック操作から LLM への補助プロンプト送信が行えること
- AC-4 いずれの検索操作においても、アプリがフリーズしたり、セッションデータや添付テキストが破損したりしないこと
- AC-5 大量データを意図的に投入した場合には、必要に応じて警告や制約（検索対象の制限など）が表示され、仕様として「軽量キーワード検索」の範囲にとどまっていることが確認できること
