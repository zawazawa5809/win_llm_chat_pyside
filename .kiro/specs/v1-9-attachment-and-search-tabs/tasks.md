# Tasks

## Overview

v1.9「添付・検索 UI をチャットから分離しつつ、右ペインをチャット／添付の 2 タブ構成に再編する」  
requirements/design に基づき、右ペインのメインタブ構造・添付タブ内レイアウト・
ショートカット・状態永続化・テスト/ヘルプ更新を段階的に実装するためのタスク分解。

## Task List

1. 右ペインのメインタブ構造

- [x] 1.1 `MainWindow.main_tabs` による「チャット／添付」タブの導入

  - 右ペインに `QTabWidget` を追加し、「チャット」「添付」の 2 タブでチャット UI と添付 UI を切り替える
  - チャットタブではチャットビュー＋メッセージコンポーザだけが表示され、添付タブではチャット本文を一切表示しない
  - _Requirements: FR-1, FR-2, FR-5, NFR-1_

- [x] 1.2 添付タブ内の上下レイアウト構成

  - 添付タブの中に `AttachmentListWidget`（添付一覧）と `AttachmentSearchPanel`（検索パネル）を上下に配置し、添付操作と検索が同一タブ内で完結するようにする
  - 添付一覧・検索パネル双方について、既存のシグナル/ドメイン API を変更せずに再利用する
  - _Requirements: FR-1, FR-5, NFR-1, NFR-4_

2. タブ切り替えショートカットとフォーカス制御

- [x] 2.1 `Ctrl+1` / `Ctrl+2` ショートカットの登録

  - `shortcut_registry` を用いて、メインウィンドウフォーカス時に `Ctrl+1` でチャットタブ、`Ctrl+2` で添付タブに切り替えるショートカットを登録する
  - ショートカットが `ShortcutHelpDialog` 上の一覧に表示されることを確認する
  - _Requirements: FR-3, NFR-2_

- [x] 2.2 タブ切り替え時のフォーカス遷移実装

  - `Ctrl+1` / `Ctrl+2` またはタブクリックで切り替えた際、チャットタブではメッセージ入力欄に、添付タブでは添付一覧または検索入力欄にフォーカスが移るようにする
  - 連続切り替え時にフォーカスが迷子にならないよう、フォーカス対象の優先順位とフォールバックルールを明示的に決めて実装する
  - _Requirements: FR-3, NFR-2, AC-2_

3. 設定によるタブ状態の永続化

- [x] 3.1 メインタブ選択状態の保存と復元

  - `config.py` の `Config` に `ui_main_selected_tab: str` を追加し、「chat」または「attachments」を保持する
  - 起動時にこの設定値を読み込み、`MainWindow` 初期化時に前回選択されていたタブを復元する
  - タブ切り替え時に設定値を即時更新し、異常系では安全なデフォルト（chat）にフォールバックする
  - _Requirements: FR-4, NFR-3, AC-3_

- [x] 3.2 （キャンセル）補助ペイン専用の状態保存

  - 旧設計で想定していた `ui.aux_pane.visible` / `ui.aux_pane.size` 等のフィールドは、補助ペイン構造を採用しないため導入しない
  - 将来別レイアウトを導入する場合は、新しい requirements/design に基づいて別タスクとして定義する
  - _Requirements: （該当なし・キャンセル）_

4. テストと回帰確認

- [x] 4.1 メインタブとショートカットのテスト

  - `tests/test_attachment_search_tabs.py` 相当のテストで、`MainWindow.main_tabs` に「チャット／添付」タブが存在しラベルが正しいこと、`_switch_main_tab` の動作、`Ctrl+1` / `Ctrl+2` が `ShortcutRegistry` に登録されていることを検証する
  - `tests/test_config.py` で `ui_main_selected_tab` のデフォルト値とマイグレーション挙動を検証する
  - _Requirements: FR-1, FR-3, FR-4, NFR-2, NFR-3, AC-2, AC-3_

- [x] 4.2 添付／検索ユースケースの回帰確認

  - 添付参照 → 添付検索 → 抜粋をチャットに貼り付け → チャット継続といったユースケースが、チャット／添付タブの導入後も既存テスト（添付・検索関連テスト）で成功することを確認する
  - レイアウト変更によって添付関連のドメインロジックやセッション保存が退行していないことを `pytest` 全体の green で担保する
  - _Requirements: FR-2, FR-5, NFR-1, NFR-3, AC-1, AC-2, AC-5_

  - _Requirements: NFR-2, AC-2_
