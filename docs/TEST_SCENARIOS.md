## 手動テストシナリオ

### 1. チャット機能

1. **基本送信**

   - [ ] メッセージを入力して送信
   - [ ] アシスタントからの応答が表示される
   - [ ] Markdown が正しくレンダリングされる

2. **ストリーミング**

   - [ ] ストリーミング応答が逐次表示される
   - [ ] ストリーミング中に停止ボタンが機能する

3. **エラーハンドリング**
   - [ ] ネットワークエラー時に適切なメッセージが表示される
   - [ ] タイムアウト時に適切なメッセージが表示される
   - [ ] 認証エラー時に適切なメッセージが表示される

### 2. マルチセッション

1. **セッション操作**

   - [ ] 新規セッションを作成できる
   - [ ] セッション名を変更できる
   - [ ] セッションを削除できる（最後の 1 つは削除不可）
   - [ ] セッション間を切り替えられる
   - [ ] 各セッションのメッセージ履歴が独立している

2. **永続化**
   - [ ] アプリを再起動してもセッションが復元される
   - [ ] セッション名の変更が保存される
   - [ ] メッセージ履歴が保存される

### 3. プロンプトテンプレート・役割プロファイル

1. **テンプレート**

   - [ ] テンプレートを作成できる
   - [ ] テンプレートを編集できる
   - [ ] テンプレートを削除できる
   - [ ] テンプレートを入力欄に挿入できる
   - [ ] アプリを再起動してもテンプレートが復元される

2. **役割プロファイル**
   - [ ] 役割プロファイルを作成できる
   - [ ] 役割プロファイルを編集できる
   - [ ] 役割プロファイルを削除できる
   - [ ] セッション作成時に役割プロファイルを選択できる
   - [ ] 既存セッションの役割プロファイルを変更できる
   - [ ] アプリを再起動しても役割プロファイルが復元される

### 4. ファイル添付

1. **添付操作**

   - [ ] PDF ファイルを添付できる
   - [ ] テキストファイルを添付できる
   - [ ] Markdown ファイルを添付できる
   - [ ] 添付ファイルのテキストが抽出される
   - [ ] 添付ファイルを削除できる

2. **要約・Q&A**
   - [ ] 「このファイルを要約」ボタンが機能する
   - [ ] 「このファイルについて質問する」ボタンが機能する
   - [ ] 抽出テキストが LLM に送信される

### 5. 検索機能

1. **セッション内検索（Ctrl+F）**

   - [ ] Ctrl+F で検索バーが開く
   - [ ] キーワード入力で検索結果がハイライトされる
   - [ ] Enter で次へ移動できる
   - [ ] Shift+Enter で前へ移動できる
   - [ ] ESC で検索バーが閉じる
   - [ ] 検索結果の件数が表示される

2. **セッション一覧検索（Ctrl+Shift+F）**

   - [ ] Ctrl+Shift+F でセッション一覧検索にフォーカス
   - [ ] キーワード入力でセッションがフィルタリングされる
   - [ ] 検索結果の件数が表示される

3. **添付テキスト検索**
   - [ ] キーワード入力で添付テキストを検索できる
   - [ ] 検索結果が一覧表示される
   - [ ] 抜粋を入力欄に挿入できる

### 6. グローバルホットキー

   - [ ] Ctrl+Alt+Space でウィンドウが前面化される

## パフォーマンステスト

### 起動時間

- [ ] 起動時間が 3 秒以内（目安）

### メモリ使用量

- [ ] 起動時のメモリ使用量が 100MB 以内（目安）
- [ ] セッション数が増えてもメモリ使用量が急増しない

### ファイル操作

- [ ] 巨大ファイル（10MB 以上）の添付時に警告が表示される
- [ ] セッション数が 100 を超えても動作が重くならない
